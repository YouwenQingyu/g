# 第七码头没有潮汐

单文件离线网页解谜游戏。案卷编号 07-0314。

## 玩法

手机浏览器直接打开 `index.html`。不需要联网，进度存在浏览器本地，误触可在页面里重置。

其余早期单页稿不参与运行，只是过程稿，所以这个目录只留这一份。
